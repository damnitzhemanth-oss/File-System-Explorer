VS Code Extension

File System Explorer

Instantly generate file trees and view your entire project's code in one document — right from the Command Palette.

⬇ Download .vsix ⭐ View on GitHub

Two Commands. Zero Config.

🌳

File Structure

Generates a clean tree view of your workspace. Run Ctrl+Shift+P → File Structure and get the full layout instantly.

📄

Entire File System

Dumps every file's content into a single document, respecting .gitignore and skipping node_modules automatically.

Install in 3 Steps

1

Download the latest .vsix file from GitHub Releases.

2

Open VS Code → Extensions view (Ctrl+Shift+X)

3

Click the ... menu → Install from VSIX... → select the file.


Or from terminal: 

code --install-extension file-system-explorer-0.0.1.vsix
